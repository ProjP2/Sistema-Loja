#  Sistema-Loja — Loja com Estoque

Sistema de gerenciamento de uma loja com controle de estoque em console, desenvolvido como projeto da disciplina Programação 2 do curso de Engenharia da Computação da UFRPE.

>  **Status:** Entrega 1 — modelagem e planejamento do sistema.

---

##  Sobre o projeto

O Sistema-Loja tem como objetivo permitir que uma loja gerencie seus produtos, o estoque disponível e o registro de vendas. Nesta primeira entrega, o foco está na modelagem do sistema: definição das classes e seus relacionamentos (UML), estrutura do banco de dados, fluxo do menu principal e funcionamento de uma venda.

---

##  Escopo da Entrega 1

- [x] Diagrama de classes (UML)
- [x] Protótipo do menu principal do sistema
- [x] Modelagem das tabelas SQL
- [x] Explicação do fluxo de venda

---

##  Funcionalidades planejadas

- Cadastro de produtos
- Controle de estoque (entrada e saída de produtos)
- Registro de vendas com atualização automática do estoque

---

##  Modelagem

Todos os diagramas estão no arquivo **`Projeto_P2`** (draw.io), localizado na pasta `docs/`, organizado em 4 páginas:

| Página | Conteúdo |
|---|---|
| **UML** | Diagrama de classes com atributos, métodos e relacionamentos |
| **Menu Principal** | Estrutura e opções do menu do sistema |
| **Tabela SQL** | Modelagem das tabelas do banco de dados |
| **Explicação de venda** | Fluxo de como uma venda é realizada e como afeta o estoque |
